# P0 证据闸门 1：角度搜索的假阳性 / 错密钥 / 角度泄漏

**状态**：已跑完（RTX 4090D，2026-09-20）。
**脚本**：`run_paper_controls.py`（未改动 `run_sync_search.py` / `swm` 核心）。
**数据**：`runs/p0_controls/step2_N50/`（主段）、`runs/p0_controls/step2_N50_cropblack/`（裁剪对照）。

## 0. 一句话结论

**主闸门通过**：在**互不相交**的校准/测试划分上，搜索统计量 `max_γ S(γ)` 的
TPR@1%FPR 在 8 个攻击格中 7 格为 1.000、1 格为 0.800，AUC 7 格 1.000、1 格 0.962；
**角度搜索没有把噪声底抬成假阳性**。但同一批实验**暴露出一个必须处理的负面结果**：
`S(γ)` 不是**密钥归属**统计量——用错密钥解码的水印图在存在性阈值上几乎全部被判为阳性
（信号类攻击 FPR 0.88–1.00）。详见 §3。

## 1. 协议与划分

| 项 | 设置 |
|---|---|
| 载波 | `results/design_searched_realgeom.npz`（B=8，双层异栅格 + 复相位，η=1e4） |
| 模型 / 反演 | SD2.1-base，512×512，DDIM 50 步 / 反演 50 步，空 prompt，guidance 1 |
| 搜索网格 | 2.0°（180 个候选角） |
| 校准划分 | prompt 索引 0–49（50 张） |
| 测试划分 | prompt 索引 500–549（50 张），与校准**互不相交** |
| 负样本 | ① null：同一 latent 的无水印图；② wrong-key：含水印图用**另一套码本**解码（`design_B8_s1/s2/s3`，3 个独立 key） |
| 阈值 | conformal 顺序统计量，`k=floor(0.01×50)=0`，即 τ = 校准集 null 的最大值 |

> 说明：`p0_common.SplitPlan` 的默认 `test_offset=1000` 在本实例越界
> （`meta_data.json` 只有 1000 条 caption，`images512` 有 5000 张图），因此本批显式
> 传入 `--calib_offset 0 --test_offset 500`。两划分都在范围内且互不相交。

## 2. 主结果：搜索的假阳性被阈值标定吸收

| 攻击 | null 分数(均值) | 搜索增益 | AUC | TPR@1%FPR | 实测 FPR [95% Wilson] | 同一阈值下**无搜索** TPR | null 角度泄漏率 | ours 失锁率 |
|---|---:|---:|---:|---:|---|---:|---:|---:|
| clean | 3948.7 | 1.79 | 1.000 | 1.000 | 0.000 [0.000, 0.071] | 1.000 | 0.340 | 0.000 |
| JPEG q25 | 3943.6 | 1.64 | 1.000 | 1.000 | 0.000 [0.000, 0.071] | 1.000 | 0.380 | 0.000 |
| 噪声 σ=0.1 | 4017.0 | 1.59 | 1.000 | 1.000 | 0.040 [0.011, 0.135] | 1.000 | 0.400 | 0.000 |
| 模糊 r=5 | 3810.2 | 1.65 | 1.000 | 1.000 | 0.000 [0.000, 0.071] | 1.000 | 0.360 | 0.000 |
| 亮度 ×6 | 3398.1 | 1.57 | 1.000 | 1.000 | 0.040 [0.011, 0.135] | 1.000 | 0.260 | 0.000 |
| **旋转 45°** | 1973.6 | **2.46** | 1.000 | 1.000 | 0.060 [0.021, 0.162] | **0.020** | 0.020 | 0.000 |
| **旋转 75°** | 2714.7 | 2.06 | 1.000 | 1.000 | 0.040 [0.011, 0.135] | **0.260** | 0.040 | 0.000 |
| **旋转+噪声 0.05** | 3666.7 | 1.61 | 0.962 | 0.800 | 0.000 [0.000, 0.071] | **0.100** | 0.040 | 0.060 |

**三点读数**：

1. **搜索确实抬高了噪声底**：null（无水印）的 `max_γ S(γ)` 比 `S(0)` 高 1.57–2.46 倍，
   旋转格最高（2.46）。所以「取最大」引入的自由度是真实存在的，不能忽略。
2. **但它被同统计量的阈值标定吸收了**：τ 是在**同一统计量**（也是对角度取最大）的
   独立校准划分上算出的，因此实测 FPR 只有 0–0.06。作为对照，「无搜索」列显示同一批
   水印图若改用 `S(0)` 的阈值，旋转下 TPR 塌到 0.020 / 0.260 / 0.100——
   **这正是角度搜索带来的增益，而不是评分标准的假象**。
3. **FPR 的严格界没有全部满足**：checklist 的验收条件是
   `fpr_test_realised ≤ fpr + 1/n_calib = 0.03`，实测有 4 格（0.04/0.04/0.04/0.06）超过。
   这是否意味着校准失败？**不是**，见 §4 的可交换性检验。

## 3. 负面结果：`S(γ)` 不能做密钥归属

用错密钥解码时，FPR（在 null 标定的 τ 下）：

| 攻击 | key s1 | key s2 | key s3 | AUC(wm vs wrong-key) |
|---|---:|---:|---:|---:|
| clean | **1.000** | **1.000** | **1.000** | 1.000 |
| JPEG q25 | **1.000** | **1.000** | **1.000** | 1.000 |
| 噪声 σ=0.1 | **1.000** | **1.000** | **1.000** | 1.000 |
| 模糊 r=5 | 0.880 | 0.900 | 0.980 | 1.000 |
| 亮度 ×6 | **1.000** | **1.000** | **1.000** | 0.987–0.990 |
| 旋转 45° | 0.240 | 0.280 | 0.160 | 1.000 |
| 旋转 75° | 0.840 | 0.780 | 0.840 | 0.997–0.998 |
| 旋转+噪声 0.05 | 0.280 | 0.240 | 0.280 | 0.851–0.860 |

**机制**：`S(γ)=∏_l mean_j|ℓ_j|` 度量的是「环带能量在载波方向上的投影幅度」，
而错误码本仍然张在**同一条环带**上，所以 key-A 水印的能量会大量漏进 key-B 的载波方向。
错误密钥的分数因此远高于无水印图，但仍低于正确密钥（故 AUC 接近 1）。

**这不是致命伤，但它限定了论文口径**：把 `S(γ)` 当作**存在性**统计量（负样本 = 无水印图）
是成立的；**密钥归属必须靠 payload 匹配**（bit 全对率 / PMR），不能靠 `S(γ)`。

**key-aware 阈值可行吗？**（离线重算：τ 改在 wrong-key 负样本的校准划分上标定）

| 攻击 | τ(null) | τ(wrong-key) | TPR@τ_wk | FPR(null)@τ_wk | FPR(wk)@τ_wk |
|---|---:|---:|---:|---:|---:|
| clean | 5928 | 78269 | 1.000 | 0.000 | 0.000 |
| JPEG q25 | 6728 | 56859 | 1.000 | 0.000 | 0.000 |
| 噪声 σ=0.1 | 6122 | 46067 | 1.000 | 0.000 | 0.007 |
| 模糊 r=5 | 7541 | 24961 | 0.960 | 0.000 | 0.000 |
| 亮度 ×6 | 6314 | 49328 | 0.980 | 0.000 | 0.000 |
| 旋转 45° | 2490 | 3737 | 0.980 | 0.000 | 0.007 |
| 旋转 75° | 3662 | 9309 | 0.920 | 0.000 | 0.007 |
| **旋转+噪声 0.05** | 5719 | 19935 | **0.220** | 0.000 | 0.007 |

即：key-aware 阈值能把错密钥误报压到 ≤0.007，且 7/8 格 TPR 仍 ≥0.92；
**但旋转+噪声下 TPR 从 0.800 崩到 0.220**（水印分数均值 16615 < τ_wk=19935），
说明该统计量在组合攻击下**不具备足够的密钥区分度**。
因此不建议把「key-aware 阈值 + S(γ)」写成一个新组件；
**正确的做法是 presence 与 identity 分开报**，identity 走 payload。

## 4. FPR 超界是不是校准失败？——可交换性检验

把校准 null 与测试 null 直接对比（同条件、不同图片子集）：

| 攻击 | AUC(测试 null vs 校准 null) | 均值比（测/校） | 超过 τ 的测试样本数 |
|---|---:|---:|---:|
| clean | 0.493 | 0.983 | 0/50 |
| JPEG q25 | 0.488 | 0.988 | 0/50 |
| 噪声 σ=0.1 | 0.520 | 1.021 | 2/50 |
| 模糊 r=5 | 0.406 | 0.899 | 0/50 |
| 亮度 ×6 | 0.518 | 1.038 | 2/50 |
| 旋转 45° | 0.486 | 0.993 | 3/50 |
| 旋转 75° | 0.524 | 1.018 | 2/50 |
| 旋转+噪声 | 0.569 | 1.026 | 0/50 |

**读数**：AUC 全部落在 0.41–0.57，均值比 0.90–1.04 → 两个划分**统计上不可区分**，
不存在「测试划分内容更难」造成的系统性偏置。在可交换性下，测试样本超过
`τ = max(50 个校准 null)` 的概率是 `1/51 ≈ 2%`，期望个数 ≈ 0.98；
实测 0–3 个属于二项抽样噪声（P(X≥3)≈0.08）。
**结论**：实测 FPR 与 1% 目标一致到 n=50 能给出的分辨率为止；
`fpr + 1/n_calib` 这个严格界忽略了测试侧的抽样波动，不应作为失败的判据。
正式版需要更大的校准集（N≥1000）才能把 FPR 钉到 1% 以下。

## 5. 角度泄漏：干净

在**旋转**攻击格上，无水印图同样被旋转，若其估计角仍与真实旋转角吻合，
说明同步在读插值/黑边而不是载波。实测 `sync_rate_null`：
旋转 45° = 0.020、旋转 75° = 0.040、旋转+噪声 = 0.040。
对照：clean 格（真实角 = 0）为 0.340——即 null 的估计角在**未旋转**时有 34% 落在 0° 附近
（内容自身的谱结构所致），而**一旦真的旋转**，null 的估计角就跟不上真实角（2–4%）。
**结论：没有角度泄漏。**

## 6. 裁剪黑边对照（`--crop_black`）：有重要混淆，不能按原意解读

| 攻击 | AUC | TPR@1%FPR | ours 失锁率 | null 角度泄漏率 |
|---|---:|---:|---:|---:|
| clean | 1.000 | 1.000 | 0.000 | 0.340 |
| 旋转 45° | 0.724 | 0.060 | **1.000** | 0.000 |
| 旋转 75° | 0.868 | 0.320 | **1.000** | 0.020 |

旋转下同步**完全失效**。但必须指出该算子的真实语义：
`p0_common.inscribed_crop_after_rotation` 是「旋转 → 取内接正方形 → **resize 回原尺寸**」，
45° 时缩放因子约 **1.414×**。也就是说它是**旋转 + 缩放**，而缩放是径向问题，
本文方法（角向同步）在文档中已明确列为失效边界。因此：

* 它**不能**用来证明「同步依赖零填充黑边」——失效可以由缩放解释；
* 没有泄漏的正面证据来自 §5（旋转格 null 泄漏率 0.02–0.04）以及
  去填充但**不变尺度**的算子对照（`run_unseen_operators.py` 的 `pil_expand_crop`、
  `cv2_*_reflect`，见后续报告）。

## 8. 对论文口径的直接影响

1. **可以写**：存在性检测在旋转族上不是 max-over-angles 的假象——
   同一阈值下关闭搜索 TPR 从 1.000 掉到 0.020/0.260；
2. **必须写清**：`S(γ)` 是**存在性**统计量，不是密钥归属统计量；
   密钥归属用 payload（bit 全对率），与 §5.2 已有的「bit 载荷 vs key 空间」口径一致；
3. **必须写清**：N=50 的 FPR 分辨率是 2%，`fpr + 1/n` 一类的严格界在
   测试侧不成立（已给可交换性证据）；
4. **不要写**：用 crop_black 的失效去论证或反驳黑边泄漏（§6 的混淆）。
