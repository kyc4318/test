# 公开基线统一协议对比（第一批：N=50，8 攻击格）

**协议**：SD2.1-base / 512×512 / DDIM 生成 50 步、反演 50 步（空 prompt、guidance 1）/
COCO-5k prompts / 单次反演 / **逐样本配对**（同 prompt、同 latent、同攻击实现）。

**基线全部使用官方开源代码**：Gaussian Shading（CVPR'24）、SFWMark HSTR/HSQR（ICCV'25，
2048 keys 穷举识别）。

**未纳入**：AnchorMark / ShapeMark / SynTag（无公开代码，按要求跳过）；Stirmark 3.1（按要求跳过）。

命令：`bash run_paper_queue.sh core`（+ `gs8`）→ 产物 `runs/paper_*/`、`logs/paper_queue.log`；
表格由 `python make_paper_tables.py` 生成。

---

## T1 载荷解码（bit payload 任务）

单元格 = `BitAcc / PMR`；PMR 为全部 8 bit 正确的图像占比（等价于在 2^8 条消息上穷举识别）。
GS-8 是**容量对齐**（同样 8 bit）对照，GS-256 是原生容量。

| 攻击 | GS-256 | GS-8（容量对齐） | **SectorSync（ours）** |
|---|---|---|---|
| clean | 1.0000 / 1.000 | 1.0000 / 1.000 | **1.0000 / 1.000** |
| JPEG q25 | 0.9964 / 0.720 | 1.0000 / 1.000 | **1.0000 / 1.000** |
| 噪声 σ=0.1 | 0.9849 / 0.460 | 1.0000 / 1.000 | **1.0000 / 1.000** |
| 高斯模糊 r=5 | 0.9567 / 0.020 | 1.0000 / 1.000 | **1.0000 / 1.000** |
| 亮度 ×6 | 0.9008 / 0.120 | 0.9875 / 0.980 | **1.0000 / 1.000** |
| **旋转 45°** | 0.4966 / 0.000 | 0.5150 / 0.020 | **0.9950 / 0.960** |
| **旋转 75°** | 0.4963 / 0.000 | 0.4875 / 0.000 | **0.9975 / 0.980** |
| **旋转 + 噪声 σ=0.05** | 0.5045 / 0.000 | 0.4825 / 0.000 | **0.9425 / 0.880** |

读法：**同容量下** GS-8 在非几何攻击上同样满分（PMR 全 1.000），但**旋转一栏无论 256 bit
还是 8 bit 都塌到随机**；GS-256 呈现"高 BitAcc、低 PMR"（blur 0.9567 / 0.020），
说明原生容量下比特仍可读、但几乎没有整条消息正确的图像。

## T2 存在性检测（水印 vs 无水印）

单元格 = `AUC / TPR@1%FPR`。

| 攻击 | GS-256 | GS-8 | **ours** | SFWMark HSQR | SFWMark HSTR |
|---|---|---|---|---|---|
| clean | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 |
| JPEG q25 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 |
| 噪声 σ=0.1 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 |
| 高斯模糊 r=5 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 1.000 | 0.998 / 0.920 |
| 亮度 ×6 | 1.000 / 1.000 | 0.984 / 0.980 | 1.000 / 1.000 | 1.000 / 1.000 | 0.978 / 0.880 |
| **旋转 45°** | 0.493 / 0.000 | 0.464 / 0.020 | **1.000 / 1.000** | 0.606 / 0.100 | 0.561 / 0.060 |
| **旋转 75°** | 0.475 / 0.000 | 0.440 / 0.000 | **1.000 / 1.000** | 0.602 / 0.020 | 0.560 / 0.100 |
| **旋转 + 噪声 σ=0.05** | 0.571 / 0.000 | 0.319 / 0.000 | **0.943 / 0.800** | 0.594 / 0.000 | 0.625 / 0.000 |

读法：旋转下 **GS 的 AUC 低于 0.5**（分数与"更像水印"反相关），即 key 区域完全失配；
SFWMark 的 HSTR/HSQR 原文攻击列表**没有旋转**，我们补测后同样是 0.56–0.63。

## T3 身份识别（key 任务，各自 key 空间）

单元格 = `Id-Acc / TPR@1%FPR`；SFWMark 用 2048 keys 穷举识别。

| 攻击 | SFWMark HSQR | SFWMark HSTR |
|---|---|---|
| clean | 1.000 / 1.000 | 1.000 / 1.000 |
| JPEG q25 | 1.000 / 1.000 | 0.900 / 1.000 |
| 噪声 σ=0.1 | 1.000 / 1.000 | 0.800 / 1.000 |
| 高斯模糊 r=5 | 1.000 / 0.920 | 0.500 / 0.920 |
| 亮度 ×6 | 0.940 / 1.000 | 0.580 / 0.880 |
| **旋转 45°** | **0.000** / 0.100 | **0.000** / 0.060 |
| **旋转 75°** | **0.000** / 0.020 | **0.000** / 0.100 |
| **旋转 + 噪声 σ=0.05** | **0.000** / 0.000 | **0.000** / 0.000 |

口径：ours 的 PMR over 2^8 与这里的 Id-Acc over 2048 keys 属于**同一类量**（对载荷穷举识别），
差别只在键空间 B=8 vs B=11；容量差异必须在表头并列标注。

## T4 同步开关消融（同一载波，唯一变量 = 是否做角度搜索）

| 攻击 | 不做搜索（γ=0）BitAcc | 做搜索 BitAcc / PMR | 失锁率（角误差>2°） | 平均角误差 |
|---|---|---|---|---|
| clean / JPEG / noise / blur / bright | 1.0000 | 1.0000 / 1.000 | — | — |
| **旋转 45°** | 0.4600 | **0.9950 / 0.960** | **0.000** | 1.00° |
| **旋转 75°** | 0.4900 | **0.9975 / 0.980** | **0.000** | 1.00° |
| **旋转 + 噪声 0.05** | 0.4650 | **0.9425 / 0.880** | **0.100** | 4.71°（p90 28.6°） |

这是本批最干净的一组证据：载波/载荷/攻击完全相同，唯一差别是解码端是否执行角度搜索。
纯旋转下失锁率为 0、平均角误差 1.00°（正好是 2° 网格的半个步长）；
旋转+噪声出现 10% 失锁，对应"真峰塌陷"，是当前的明确 limit。
