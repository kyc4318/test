included verbatim so that the numbers can be audited.

(the per-sample `rows.jsonl` files are large and are regenerated by the scripts).

## A note on cross-references

These reports were extracted from a larger working project. A few of them cite
**internal documents that are deliberately not part of this repository**, namely

* the manuscript draft (`paper_methods_experiments_draft.md`) — unpublished text;
* the earlier phase reports (`phase3_sync_energy_and_carrier.md`,
  `P0_sync_diagnostics_N50.md`, `P0.5_codebook_search.md`,
  `shift_identifiable_search.md`, …) — superseded progress notes;
* the internal strategy/planning documents.

Where a report cites one of those, the cited number can in almost all cases be
reproduced from the scripts and designs shipped here; treat a missing
cross-reference as "context available on request", not as a missing measurement.

## Scale disclaimer

Everything here is **pilot scale** (`N=50` per cell unless the report says
otherwise, and the operator-generalisability stage used `N=15`). Use the
confidence intervals, not the point estimates, and read the
"Known caveats" section of the top-level README before quoting any number.
