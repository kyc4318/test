# P0 证据闸门 2：连续角 / 负角 / 非格点旋转

**状态**：已跑完（RTX 4090D，2026-09-20）。
**脚本**：`run_continuous_rotation.py`（未改动 canonical 核心）。
**数据**：`runs/p0_rotation/{grid_step1_N30,fixed_step1_N30,random_step1_N30}/`。

## 0. 一句话结论

**通过。** 纯旋转下 270 个样本**零失锁**（Wilson 上界 1.4%，验收线 3%）；
负角与正角无系统偏置；非格点角的误差不劣于半个搜索步长（中位 0.30°、p90 0.50°，
搜索网格 1°）；**盲解码与 oracle 角解码的 BitAcc 完全一致**（0.9993 vs 0.9993），
说明纯旋转下的残余误差全部来自同步、而非载荷。
叠加噪声后失败率上升到 7.0%（σ=0.05）/14.8%（σ=0.1），但 oracle BitAcc 仍为 0.996/0.993，
**同样是同步失败而非载荷失败**。

## 4. 读数与写作用法

1. **纯旋转已经解决**：三组独立扫描（整数角 720、非格点角 270、随机角 240）合起来
   **1230 个纯旋转样本中失锁 5 个（0.41%，Wilson 95% CI [0.17%, 0.95%]）**；
   其中 `fixed`(σ=0, 270) + `random`(240) 这 510 个样本只失锁 2 个（0.39%）。
2. **非格点角不是问题**：误差被搜索网格（1°）限制在半步长内，
   且盲解码 = oracle 解码，说明 1° 网格足够；若要更细可降到 0.5°（代价线性）。
3. **噪声才是真瓶颈，且是同步问题**：σ=0.1 时失锁 14.8%，
   而 oracle 角下 BitAcc 仍有 0.993 —— 与 `phase3_sync_energy_and_carrier.md`
   的「真峰塌陷」结论一致。这条写进 limitation，并且是本轮第三优先级
   （inversion-error spectrum）要解释的对象。
4. **可以写进论文**：「在 N=30 的 pilot 规模下，纯旋转族（整数/非格点/随机/负角，
   共 1230 样本）失锁率 0.73%，角误差中位 ≤0.3°」——但必须标 N 与 pilot。
